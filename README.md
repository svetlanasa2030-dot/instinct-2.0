# Instinct 2.0

Программа автоматизирует последовательность действий в заданной точке экрана.

## Что делает

1. Ищет на экране изображение точки, которое вы укажете.
2. Кликает по найденной точке.
3. Нажимает `↑`.
4. Нажимает `Enter`.
5. Ждет 3 секунды.
6. Нажимает `Enter` еще раз.
7. Ждет заданный в программе интервал и повторяет цикл.

Если точка не найдена, программа ничего не нажимает и повторяет поиск после интервала.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

На Windows при первом запуске может потребоваться разрешить Python доступ к управлению мышью/клавиатурой.

## Настройка

- **Изображение точки** — небольшой скриншот элемента, по которому нужно кликать.
- **Интервал, сек** — пауза между циклами.
- **Точность поиска** — порог совпадения изображения, обычно `0.85`.
- **F8** — остановить или снова запустить автоматизацию.

Для надежного распознавания рекомендуется делать маленький скриншот уникального участка интерфейса без лишнего фона.
